# Getting help

## Using the Postman MCP Server

- **Documentation** —
  [Postman MCP Server overview](https://learning.postman.com/docs/postman-ai-agent-builder/mcp-requests/overview/)
  covers installation, client configuration, and the available tools.
- **Client setup examples** — See the [README](./README.md) for Claude, Cursor, VS
  Code, and other MCP clients.
- **Docker** — See [DOCKER.md](./DOCKER.md).
- **Try the tools** — Connect to the local or remote server and exercise it with the
  [Postman MCP Server collection](https://www.postman.com/postman/postman-public-workspace/collection/681dc649440b35935978b8b7).

## Questions

For "how do I…" questions — setup, MCP clients, workflows — the
[Postman Community](https://community.postman.com/) is the fastest place to get an
answer, and other people benefit from the thread.

## Your Postman account, billing, or the Postman API

Those aren't handled in this repository. Contact
[Postman support](https://support.postman.com/).

## Bugs and tool requests

Open an issue — this is the right place, and it's how tool fixes and new tools get
made:

- [Bug report](https://github.com/postmanlabs/postman-mcp-server/issues/new?template=bug_report.yml)
- [Tool request](https://github.com/postmanlabs/postman-mcp-server/issues/new?template=tool_request.yml)
- [Documentation issue](https://github.com/postmanlabs/postman-mcp-server/issues/new?template=docs_issue.yml)

See [CONTRIBUTING.md](./CONTRIBUTING.md) for what makes a report actionable, and for
which files accept pull requests directly.

## Security

Don't open a public issue for a suspected vulnerability. See
[SECURITY.md](./SECURITY.md).
